# 3-digests

Histórico de cada lote: el `summary-<lote>.md` que el agente deja en `1-inbox/` al procesarlo se archiva aquí cuando llega el siguiente lote. Es el análisis de ese lote (qué entró y qué conviene entender), no la base de conocimiento, que está en `4-data/`.

No se reescribe. Si se corrige algo después, el cambio va a `4-data/` y aquí se añade al final una sección «Correcciones posteriores» con la fecha.
