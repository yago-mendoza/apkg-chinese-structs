# Estructuras de frase

## Estructuras

- ✅🃏 `{S} + 很 + {Adj}` · Describir: el adjetivo va sin 是 y con 很 delante, aunque no signifique «muy». · 他很高。 / 天气很冷。 / 北京很热。
- ✅🃏 `{S} + 不 + {Adj}` · Negar una descripción: 不 delante del adjetivo, sin 很 ni 是. · 她不漂亮。 / 他不高。 / 天气不冷。
- ✅🃏 `{S} + {Adj} + 吗？` · Preguntar por una descripción: el adjetivo solo y 吗 al final. · 她漂亮吗？ / 天气冷吗？
- ✅🃏 `{S} + {Adj} + 不 + {Adj}？` · Pregunta de sí o no sin 吗: el adjetivo, 不 y el adjetivo otra vez. · 她漂亮不漂亮？
- ✅🃏 `太 + {Adj} + 了！` · Exclamar: ¡qué…!, ¡demasiado…! · 太好了！
- ✅🃏 `{S} + 也 + 很 + {Adj}` · Yo también: 也 va detrás del sujeto y delante de 很. · 我也很好。
- ✅🃏 `{S} + 是 + {N}` · Decir qué o quién es algo: 是 une dos nombres, nunca un nombre y un adjetivo. · 我们是朋友。 / 我是工程师。 / 这是我的手机。
- ✅🃏 `{S} + 不 + 是 + {N}` · Negar lo que es algo: 不是. · 我不是学生，我是老师。
- ✅🃏 `{S} + 是 + {Lugar} + 人` · Decir la nacionalidad: país + 人. · 我是西班牙人。
- ✅🃏 `{S} + 的 + {N}` · Posesión: el poseedor, 的 y la cosa (我的手机, mi móvil). · 这是我的手机。
- ✅🃏 `{S} + 叫 + {Nombre}` · Decir cómo se llama alguien. · 我叫雅戈。
- ✅🃏 `{S} + 姓 + {Nombre}` · Decir el apellido. · 我姓门多萨。
- ✅🃏 `{S} + 来自 + {Lugar}` · Decir de dónde eres. · 我来自西班牙。
- ✅🃏 `{S} + 呢？` · Devolver la pregunta: ¿y tú? · 我很好，你呢？
- ✅🃏 `{S} + 都 + {V}` · Todos: 都 va detrás del sujeto y delante del verbo. · 我们都是学生。 / 大家都来了。 / 我们都喜欢打篮球。
- ✅🃏 `请 + {V}` · Pedir con cortesía: 请 delante del verbo. · 请喝咖啡。
- ✅🃏 `{S} + 想 + {V}` · Tener ganas de hacer algo. · 我想去商店。 / 我想买东西。
- ✅🃏 `{S} + 要 + {N}` · Pedir o querer una cosa. · 我要水。 / 我要牛肉。
- ✅🃏 `{S} + 喜欢 + {V}` · Decir que te gusta hacer algo. · 我喜欢喝咖啡。 / 我喜欢看书。
- ✅🃏 `{S} + 在 + {V}` · Estar haciendo algo ahora: 在 delante del verbo. · 我在看书。
- ✅🃏 `{S} + {V} + 了` · Algo ya ha pasado o ha cambiado: 了 detrás del verbo. · 大家都来了。 / 我走了。
- ✅🃏 `{Num} + 个 + {N}` · Contar: número, clasificador y nombre; delante del clasificador, 两 y no 二. · 我有三个朋友。 / 他们有两个孩子。
- ✅🃏 `{N} + 在 + 哪里？` · Preguntar dónde está algo. · 商店在哪里？
- ✅🃏 `{N} + 和 + {N}` · Unir dos nombres: 和 es «y» solo entre nombres, nunca entre frases ni adjetivos. · 我喜欢咖啡和巧克力。
- ✅🃏 `{S} + {Tiempo} + 在 + {Lugar} + {V} + {N}` · El orden de la frase: sujeto, cuándo, dónde, qué haces y qué. El cuándo y el dónde van antes del verbo. · 我昨天在家看书。
- ✅🃏 `{S} + 没 + {V}` · Lo que no pasó: 没 delante del verbo, sin 了. El chino no conjuga: 了 dice que pasó; 没, que no. · 我没吃饭。
- ✅🃏 `{S} + {V} + 过 + {N}` · Haber hecho algo alguna vez: 过 detrás del verbo. · 我去过北京。 / 你看过这个电影吗？
- ✅🃏 `{S} + 比 + {N} + {Adj}` · Comparar: A 比 B + adjetivo, «A es más … que B». · 他比我高。
- ✅🃏 `{S} + 最 + {V} + {N}` · Lo que más: 最 delante del verbo o del adjetivo. · 我最喜欢中国菜。
- ✅🃏 `虽然 + {Frase} + 但是 + {Frase}` · Aunque…, …: en chino se dicen las dos partes, 虽然 y 但是. · 虽然很累，但是我很高兴。
- ✅🃏 `{S} + 又 + {Adj} + 又 + {Adj}` · Dos cualidades a la vez: 又 + adjetivo + 又 + adjetivo. · 她又高又漂亮。
- ✅🃏 `{S} + 一边 + {V} + 一边 + {V}` · Dos acciones a la vez: 一边 + verbo + 一边 + verbo. · 他一边吃一边说。
- ✅🃏 `{S} + 会 + {V}` · Saber hacer algo aprendido (y también predecir: 明天会下雨). · 我会说中文。 / 明天会下雨。
- ✅🃏 `别 + {V}` · Pedir que alguien no haga algo: 别 delante del verbo. · 别看我！
- ✅🃏 `{S} + {V} + {N} + {V} + {N}` · Acciones en cadena, en el orden en que pasan: primero el medio, luego la meta. · 我坐飞机去中国。
