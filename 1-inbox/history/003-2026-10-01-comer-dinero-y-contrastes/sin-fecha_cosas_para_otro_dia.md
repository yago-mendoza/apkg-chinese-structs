- 我有钱。Wǒ yǒu qián. → Tengo dinero.
- 我没有钱。Wǒ méiyǒu qián. → No tengo dinero.
- 这是钱。Zhè shì qián. → Esto es dinero.
多少 — duōshao — cuánto / cuántos
Se usa cuando preguntas por una cantidad y no sabes aproximadamente cuál es.
- 多少钱？Duōshao qián? → ¿Cuánto dinero? / ¿Cuánto cuesta?
- 这个多少钱？Zhège duōshao qián? → ¿Cuánto cuesta esto?
- 你有多少钱？Nǐ yǒu duōshao qián? → ¿Cuánto dinero tienes?
 — chī — comer
Es un verbo.
- 我吃。Wǒ chī. → Como.
- 我吃饭。Wǒ chī fàn. → Como / voy a comer.
- 你吃什么？Nǐ chī shénme? → ¿Qué comes?
- 我吃米饭。Wǒ chī mǐfàn. → Como arroz.
饭 — fàn — comida / arroz cocido
饭 puede significar “comida” en general, aunque originalmente está relacionado con el arroz cocido.
La combinación más importante es:
吃饭 — chī fàn — comer
- 你吃饭吗？Nǐ chī fàn ma? → ¿Comes? / ¿Vas a comer?
- 我们吃饭。Wǒmen chī fàn. → Comemos / vamos a comer.
- 吃饭了吗？Chī fàn le ma? → ¿Has comido ya?
Ahora las palabras interrogativas.
谁 — shéi / shuí — quién
Las dos pronunciaciones existen; shéi es muy habitual al hablar.
- 他是谁？Tā shì shéi? → ¿Quién es él?
- 你是谁？Nǐ shì shéi? → ¿Quién eres?
- 谁吃饭？Shéi chī fàn? → ¿Quién come?
- 这是谁的钱？Zhè shì shéi de qián? → ¿De quién es este dinero?
Una cosa importante: en chino normalmente 谁 ocupa el lugar de la persona que desconoces.
他是老师。→ Él es profesor.
他是谁？→ Él es quién → ¿Quién es él?
几 — jǐ — cuántos
几 se usa normalmente para cantidades pequeñas o cuando esperamos un número relativamente pequeño.
- 几个人？Jǐ ge rén? → ¿Cuántas personas?
- 你几岁？Nǐ jǐ suì? → ¿Cuántos años tienes?
- 几块钱？Jǐ kuài qián? → ¿Cuántos yuanes?
- 你吃几个？Nǐ chī jǐ ge? → ¿Cuántos comes?
La diferencia básica es:
几 → cuántos, normalmente cantidad pequeña.
多少 → cuánto/cuántos, cantidad abierta.
Por ejemplo:
你有几个苹果？→ ¿Cuántas manzanas tienes?
你有多少钱？→ ¿Cuánto dinero tienes?
怎么 — zěnme — cómo
Pregunta por la manera de hacer algo.
- 怎么吃？Zěnme chī? → ¿Cómo se come?
- 怎么说？Zěnme shuō? → ¿Cómo se dice?
- 这个怎么吃？Zhège zěnme chī? → ¿Cómo se come esto?
- 你怎么去？Nǐ zěnme qù? → ¿Cómo vas?
Una estructura muy útil es:
怎么 + verbo？
怎么吃？→ ¿Cómo se come?
怎么说？→ ¿Cómo se dice?
怎么写？→ ¿Cómo se escribe?
Con estas palabras ya puedes formar preguntas bastante útiles:
这是谁的？ Zhè shì shéi de? → ¿De quién es esto?
这个多少钱？ Zhège duōshao qián? → ¿Cuánto cuesta esto?
你吃什么？ Nǐ chī shénme? → ¿Qué comes?
几个人？ Jǐ ge rén? → ¿Cuántas personas?
这个怎么吃？ Zhège zěnme chī? → ¿Cómo se come esto?
En chino, los clasificadores se usan sobre todo cuando señalas o cuentas una unidad concreta de un sustantivo contable: por eso 这棵树 (zhè kē shù) significa “este árbol”, donde 棵 (kē) es el clasificador específico para árboles. En cambio, 钱 (qián, dinero) suele tratarse como una cantidad o masa, así que puedes decir simplemente 这是钱 (zhè shì qián), “esto es dinero”, sin clasificador; solo aparece una unidad cuando cuentas dinero, por ejemplo 一块钱 (yí kuài qián), “un yuan”.
